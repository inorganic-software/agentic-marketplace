# Bye world

Create a file named `bye-world.txt` in the current working directory. Its content is exactly this line, followed by a newline:

```
Bye world
```

- If the file already exists, overwrite it.
- Do not create or change any other file.
- When you are done, reply with the path of the file you wrote.
